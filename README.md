# Corporate-Law Annotation Dashboard
This is a static GitHub Pages site that visualizes aggregated, automated annotations from three corporate-law course PDFs.
## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `.nojekyll`, and this `README.md` to the repository root.
3. On GitHub, open **Settings** → **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.
6. GitHub will display the public Pages URL after deployment.
## Important limitation
The dashboard visualizes preliminary model output only. It does not contain the source PDFs, full annotation files, or API credentials, but its legal classifications require independent verification before reliance.
